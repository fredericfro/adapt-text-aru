Déploiement sur iOS & Android

Comment transformer cet outil web en application native mobile

Solution 1 : Progressive Web App (PWA) - Instantané

Cette application est 100% responsive et optimisée tactile. Vous pouvez l'ajouter directement sur l'écran d'accueil de votre iPhone/iPad ou Android via Safari/Chrome ("Ajouter à l'écran d'accueil") pour une utilisation hors-ligne.

Solution 2 : React Native / Expo (Application App Store / Play Store)

Pour publier directement sur l'App Store iOS et Google Play Store avec accès à la caméra du téléphone pour scanner les feuilles de cours instantanément :

  • Scan Caméra : Intégration de react-native-document-scanner-plugin pour recadrer automatiquement les documents.
  • Moteur OCR Native : Utilisation de MLKit OCR (Google) ou iOS Vision Framework pour une extraction ultra-rapide sans serveur.

Solution 3 : CapacitorJS (Wrap Hybride)

Encapsulez ce code HTML/JS directement dans un projet Capacitor avec la commande npx cap add ios / android pour obtenir un fichier `.ipa` et `.apk` prêt en quelques minutes.
